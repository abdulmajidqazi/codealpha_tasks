# CodeAlpha Hangman Game 🎮

This is a simple Hangman Game developed in Python as part of my CodeAlpha Internship Task.

## 📁 Files

- hangman.py - Main Python game file
- README.md - Project documentation

## 🎮 How to Play

1. Run the hangman.py file.
2. The game randomly selects a word.
3. Guess the word by entering one letter at a time.
4. You have a maximum of 6 incorrect guesses.
5. Guess all the letters correctly to win the game.

## 🛠️ Technologies Used

- Python
- Random Module
- Command Line Interface (CLI)

## ▶️ Run the Game

Open a terminal in the project folder and run:

python hangman.py

## ✨ Features

- Random word selection
- Letter guessing
- Incorrect guess tracking
- Input validation
- Prevents repeated guesses
- Win and game-over messages
