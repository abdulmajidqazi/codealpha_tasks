# CodeAlpha Stock Portfolio Tracker 📈

This is a simple Stock Portfolio Tracker developed in Python as part of my CodeAlpha Internship Task.

## 📁 Files

- stock_portfolio_tracker.py - Main Python program
- README.md - Project documentation

## 📊 About the Project

This program allows users to track their stock portfolio by entering stock names, quantities, and prices. It calculates the total value of the portfolio based on the entered information.

## 🛠️ Technologies Used

- Python
- Dictionaries
- Loops
- User Input
- Basic Calculations
- Command Line Interface (CLI)

## ▶️ Run the Program

Open a terminal in the project folder and run:

python stock_portfolio_tracker.py

## ✨ Features

- Add stock information
- Enter stock quantity
- Enter stock price
- Calculate total investment value
- Display portfolio information
- Simple command-line interface
